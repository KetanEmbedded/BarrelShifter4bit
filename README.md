# 4-Bit Barrel Shifter in Verilog

This repository contains a **4-bit barrel shifter** implemented in Verilog.

## Features
- Supports **Left Shift** and **Right Shift**
- Shift amounts from 0 to 3
- Combinational logic (no clock required)
- Includes **testbench** for simulation

## Files
- `barrel_shifter_4bit.v` → Verilog module for the barrel shifter
- `tb_barrel_shifter.v` → Testbench to verify the functionality
- `README.md` → Project description

## How to Simulate
1. Open in **ModelSim / Vivado / Icarus Verilog**
2. Compile both the module and testbench
3. Run simulation and check the waveform or output console
